# Images Directory

Place your images here:

## Required Images:
- `logo.svg` - Your Foyer logo (SVG format recommended for scalability)
- `hero-image.png` - Main hero section image (screenshot of your app)
- `about-image.png` - About section image
- `favicon.ico` - Website favicon

## Recommended Sizes:
- Hero image: 800x600px or larger
- About image: 600x400px or larger
- Logo: SVG format preferred, or PNG with transparent background
- Favicon: 32x32px or 16x16px

## Supported Formats:
- PNG, JPG, SVG, WebP
- Use WebP for better performance where supported
